Method

  • Each table row is emitted with a Source column from its source ids. The build aborts on missing/unknown/dead sources or cell-count mismatches.
  • Official license values were read directly from CSLB on 2026-11-08; exact record timestamps are preserved in source_checks.json.
  • The verifier parses every generated canonical page: every tbody row must have a source link; internal links/anchors must resolve; external links must exist in the ledger; dead sources may not be linked.
  • Privacy and template-marker sweeps run over published text assets. A separate line-by-line repository audit scans every tracked text file (repo_audit.md).
  • After merge, the Pages build for the exact final SHA and live content are checked and recorded on the shared board.
✓

Interpretation of blank. Owner-provided values have no official public source. Their verified cells are blank and flagged; original figures are transcribed only on labeled report/brief pages. This preserves completeness without presenting unverified values as confirmed.
