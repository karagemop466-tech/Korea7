Method

  1. Each table row is emitted with a Source column built from its source ids. The build script aborts if any row has no source, cites an unknown source, or cites a source marked dead.
  2. Every official value was read directly from the issuing site on 2026-11-07; CSLB License Detail pages printed a “Data current as of 11/7/2026” stamp.
  3. The verifier parses every generated HTML file: every <tbody> row must contain a link; every internal link (pages, CSS, JS, anchors) must resolve to an existing file; every external link must exist in the source ledger; no dead source may be linked from a row.
  4. A privacy sweep greps all published HTML/MD/JSON/CSS/JS for internal-only hiring-constraint wording and returns zero matches.
  5. After merge, the live GitHub Pages URL is fetched and the Pages build status is checked with the GitHub API.
✓

Interpretation of “blank”. Owner-provided values (the three quotes and the problem description) have no official public source. Their verified value cells are blank and flagged; the original figures are transcribed only on the explicitly labeled Project brief page and on Flagged for Review. This preserves all entries without presenting an unverified value as confirmed.
