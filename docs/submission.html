Submission guide

STOP — no approved file

There is no validated, unique TIFF to download in this repository. Do not use a historical submission as a substitute. The preflight script checks format only and cannot approve a file for submission.

When a future candidate has passed every gate

  1. Confirm its run card documents holdout DTI, confidence interval, canaries, novelty comparisons, raster hash and full validation, and that the separate selector permits a weekly slot.
  2. Download the exact candidate named in the run card, and verify its SHA-256 matches.
  3. On the competition submission page, choose the single-band GeoTIFF. Check its name and use the run card's short note (at most 140 characters).
  4. Submit and retain the organizer receipt and score; distinguish it from holdout results. If the platform rejects the file, do not silently resubmit: preserve the error and investigate.

The local validator requires finite values in [0,1] everywhere, even outside the footprint, and matching the official reference grid. This is conservative, not a guarantee of organizer acceptance.
