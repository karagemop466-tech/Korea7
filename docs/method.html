Method: calibrated sparse emission (CSE-1)

Everything on this page is either exact arithmetic on the metric or a simulation whose calibration is shown. Nothing is an organizer score.

1. Hypothesis

The gap between the 0.24-0.28 cluster of public submissions and the 0.44 leader is produced mainly by the emission step - how a probability field becomes a raster - and by the quality of per-cell evidence, not by model capacity. The metric is unusual enough that a model which is good by AUC can still be worthless: true positives are credited with a maximum over a 300 m kernel, false positives are charged as a sum over every positive pixel.

2. Mechanism

k(d) = max(1 - d/300 m, 0) TP_w = sum_{g in G} max_x p(x) k(d(x,g)) (MAX) FP_w = sum_{x: p(x)>0} p(x) (1 - max_g k) (SUM) DTI = TP_w / (TP_w + 0.2 FP_w + 0.8 FN_w)

Three consequences, each measured rather than asserted:

  1. Density is a pure cost. A 1-px band on target scores 1.0000, 3 px scores 0.8333, 5 px scores 0.6250. (Exact, gems.metric.band_table.)
  2. A background is fatal. A uniform 0.02 field over 201x201 cells with one true fault cell scores 0.0001. This is why smooth U-Net outputs land at 0.02-0.04 while sparse binary maps land at 0.25.
  3. Misses cost four times what false alarms cost (beta 0.8 vs alpha 0.2), so the optimum is not "be conservative": it is "include every cell whose probability exceeds lam*alpha/(1 - lam(1-beta))", which at lam = 0.4 is about 8%.

3. Pipeline as implemented

  1. Independent features (gems/features.py): for each band, a scale-normalised Hessian ridge response at two scales plus a gradient magnitude. A ridge measure responds to linear second-derivative structure - scarps, magnetic lineaments, topographic breaks - and is invariant to a monotone brightness change of the band.
  2. Catalogue features, recomputed inside every fold from the visible faults only: proximity, distance, tip extensions, gap closures, wide proximity.
  3. Model (gems/model.py): ridge logistic regression by Newton/IRLS, class-balanced. The balance is not cosmetic. With unbalanced weights a "distance to mapped faults" feature separates the training data almost perfectly and drives the intercept to -30 or lower; the model then returns probability 0 for every withheld segment. Measured on the demo set: catalogue-inclusive holdout DTI 0.0000, independent-features holdout DTI 0.5232.
  4. Calibration (gems/calibrate.py): isotonic (pool-adjacent-violators) score to probability, fitted on training folds only. Not cosmetic either: FP is a sum of values, so a miscalibrated field is charged for its optimism.
  5. Emission (gems/emission.py): Dinkelbach thresholding, emitting a binary map. See section 5 for the coverage-aware alternative and why it is not the default.
  6. Gates: buffered segment holdout, leakage canary, format validator, registry uniqueness, run card.

4. Holdout design (the part most projects get wrong)

  • Whole connected fault segments are withheld, never pixels.
  • A 5 px (500 m) buffer around each withheld segment is removed from training and from scoring: a model should not be punished for the experimenter's hole, and must not learn its rim.
  • Catalogue features are recomputed per fold, so the model cannot read the answer from the catalogue it is being tested against.
  • The 95% interval resamples segments, because pixels along one fault are strongly correlated and a pixel bootstrap would be far too narrow.
  • Each feature is tested alone: AUC above 0.90 is reported as a leakage-canary trip and blocks promotion.

5. Results, including the negative ones

Negative result (E2). On five calibrated testbed networks with evidence AUC 0.807, the best emitter was plain top-k (0.7169 +/- 0.0277), then Dinkelbach threshold (0.6086 +/- 0.2384), then NMS (0.5464 +/- 0.1804); the coverage-aware greedy that this project set out to justify scored 0.4850 +/- 0.0849, i.e. 0.23 worse than top-k, and worse even than top-k at the same number of emitted cells (0.3971). The greedy over-emits. The shipped default is therefore the measured winner; the coverage emitter ships tested, documented and losing.

Negative result (implicit in E3). Catalogue geometry is not a shortcut to a high score against unmapped faults: tip extension 0.0133 +/- 0.0057, gap closure 0.0032 +/- 0.0036, both 0.0146 +/- 0.0059, versus 0.2705 +/- 0.0408 for a weak evidence field. The catalogue-anchored family that dominates the public lists works because the real evaluator is kinder to catalogue-adjacent placement than our R2 reading, not because geometry finds new faults.

Positive result. Two things are worth a weekly slot: (a) removing the dense / dilated emission habit, worth +0.15 to +0.17 DTI in E2; and (b) adding genuine per-cell evidence, which in E3 moves the score from 0.015 to 0.27 at AUC 0.62-0.65 and whose ceiling is 0.59 when placement is perfect. That is where the 0.4413 leader is, and it is where the next increment is.
