A cautious repair plan for a stuck bathtub trip lever

The overflow trip lever appears stuck in concealed waste-and-overflow plumbing. Multiple plumbers have reportedly declined to force removal because of the risk of damaging hidden piping. The practical priority is a licensed plumber experienced with access-limited bathtub waste/overflow work, paired with a coordinated drywall finish plan if ceiling access is required.

Prepared from the project brief, public CSLB license records, SF.gov guidance, and Yelp listings. No contractor has been contacted, availability is unknown, and no recommendation is a performance guarantee.
Preferred outcome
Access from above

Ask first whether the assembly can be removed/repaired safely from the tub side without force or damage. Do not assume this is feasible; five prior plumbers reportedly raised concern.

Fallback approach
Access from below

If needed, coordinate an agreed inspection opening in the storage-room ceiling, plumbing work, and drywall patch/finish. The storage area is occupied/used; schedule access and protect belongings.

Strongest next step
One written scope

Request a site visit and a written, not-to-exceed diagnostic price that separates plumbing, access opening, patching/texture/paint, and any permit/inspection costs.

Important code / permit checkpoint

Do not assume no permit is required. SF.gov says a plumbing permit is needed before cutting into or replacing pipes, especially pipes that will be covered by a wall; it references exemptions in Plumbing Code §104.2. The exact determination depends on the actual scope. Ask the licensed contractor to identify the applicable requirement and obtain DBI guidance if unclear before concealed piping work.

This dashboard does not determine whether this specific repair is exempt. See SF.gov plumbing/mechanical permit guidance and the linked code section.

Recommended work sequence

  1. Screen the right skill set. Ask whether the plumber has handled stuck bathtub waste-and-overflow trip levers where the linkage is seized or trapped and access is limited; request a similar-job reference or anonymized example.
  2. Inspect before committing to destructive access. Share photos/video and explain the prior failed removal attempts. Ask the plumber to state what can safely be assessed from above, and what signs would make them stop and propose access below.
  3. Price both routes. Get separate written line items for safe above-tub work, diagnostic opening from below, plumbing repair/replacement, protection/cleanup, and drywall patch/finish/paint. Clarify who performs and warrants each trade.
  4. Agree on tenant-safe logistics. Set the service window, notice/access arrangements, containment and dust control, protection of stored items, water shutoff plan, cleanup, and a clear stop-work/approval point before enlarging any opening.
  5. Confirm code and closeout. Have the contractor confirm permit/inspection obligations for the defined work before any concealed pipe is cut, replaced, or covered. Keep the written scope, license check, change orders, photos, and paid invoice.

Suggested request for bids

“We need diagnosis and repair of a bathtub waste-and-overflow trip-lever mechanism that is stuck in concealed plumbing. Several plumbers have advised against forcing removal due to risk to the piping behind the wall. Please assess whether safe removal from the tub side is possible; if not, quote a controlled access opening from the ceiling below, the plumbing repair, and coordination of ceiling patch/finish. The area below contains stored items and the unit is occupied, so please describe protection, dust control, access timing, cleanup, and a stop-work approval point. Please separate each cost, state your license number, explain the permit/inspection requirements for the proposed scope, and confirm whether drywall repair is in your contract or handled by a named subcontractor.”

This avoids publishing personal circumstances while preserving the relevant technical and scheduling facts. Do not promise permit-free work; ask for an accurate scope-specific determination.
