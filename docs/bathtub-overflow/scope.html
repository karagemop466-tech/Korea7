Permit checkpoint (scope-specific)

SF.gov currently states that a permit is needed before cutting into or replacing pipes, particularly pipes that will be covered by a wall, while pointing to exemptions in Plumbing Code §104.2. The description includes possible access to concealed plumbing, but there is not enough information to determine whether a particular access/repair method falls under an exemption.

Action: Before work is scheduled, ask the licensed contractor to describe the exact scope and required permit/inspection path. If unclear, contact SF DBI. Do not cover repaired or replaced pipes before any required inspection.
