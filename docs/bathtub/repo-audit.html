Category · Repo audit

This repository, checked against its own claims

The repo is not about bathtubs. It is a DOE GEMS geothermal fault-prospectivity audit. This page records 14 checks that passed and 5 irregularities, each measured in this session rather than asserted.

What this repository is. A Python research and audit package for the DOE GEMS competition (DrivenData #306): single-band GeoTIFFs of “fault dots” on a 100 m grid in EPSG:32611, with an internal holdout evaluator, a submission validator, a pytest suite, and a static GitHub Pages site under docs/. The bathtub project in this session is unrelated to its contents, so all new work was placed in new paths and nothing existing was restructured.

Irregularities

F-01 · MEDIUM

A file named …-30000dots-… contains 10,944 dots.

The raster's own receipt discloses n_dots: 10944, n_dots_target: 30000. The filename does not. Any citation of the name asserts 2.7× the real count.

F-02 · HIGH

The parallel lane's stated FAIL reason is measurably inverted.

Three rasters are said to fail because their origin (243350, 4508550) “differs from the recorded grid (250000, 4520000)”. Measured: those rasters are at (243350, 4508550), which is exactly the repo's own grid.py TRANSFORM. The only file at (250000, 4520000) is an unrelated zero probe.

F-03 · MEDIUM

The “off-catalogue” relay lane puts 72 dots on the mapped catalogue.

72 of 10,944 non-zero cells coincide with data/labels.tif (0.66%). The two promoted candidates score 0 on the same test.

F-04 · LOW

GitHub Pages serves the repo root, not docs/.

Pages API reports source.path: /, so the landing URL renders README.md and the designed site is one level down at /docs/.

F-05 · LOW

format_probe_score_0.0000_do_not_submit.tif is served publicly.

It is all zeros and named as a warning, but it is still a live, submission-shaped download next to real candidates.

None of these were fixed in this session: the GEMS files are outside this session's file scope, and F-02 is a substantive research question rather than a typo. All five are logged in COORDINATION.md and on Flagged for review.

Bottom line

The measured engineering is solid: tests pass, hashes match, ZIPs are byte-identical, the grid is consistent, and the catalogue discipline is real. The weak point is prose that outran the data in two places — a filename that overstates a dot count by 2.7×, and a FAIL verdict whose stated reason is measurably backwards. In a repository whose entire value is auditability, F-02 should be corrected before the next session builds on it.
