How these were found and verified

  1. Find a licence number. Public web search for San Francisco plumbing contractors, then the licence number printed on the firm's own website or a plumbing directory. Directories were used only to obtain the number — never as the source of the licence status.
  2. Load the official record. Each number was opened at CSLB License Detail and the status, classifications, dates, bond and workers' compensation were transcribed verbatim.
  3. Apply the rule. A row is active only if the official page said “This license is current and active.” Anything else is transcribed and excluded.

CSLB's own statewide master file is available at no charge from the Public Data Portal, but it is served behind a form and could not be downloaded from this environment. Per-licence verification was used instead, which is the more precise check anyway.

The “all in one service” answer

Exactly one San Francisco firm in this set holds C-36 Plumbing and B General Building on the same licence: Ace Plumbing & Rooter, #829071. A B licensee may contract for and oversee a project requiring more than two trades, and may perform the work or sub-contract parts of it, which is precisely the “plumbing plus drywall, one company” requirement.
