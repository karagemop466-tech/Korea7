Which is the best submission to obtain a high score?

Download GEMSDOE32's h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros (0.2778) — it is the highest-reported submission across the nine focus sites.

Reality check: 0.2778 is still well below the public leaderboard #1 (0.4413) and below the 0.3195 benchmark cited in the project prompt. To win, a new, unique, holdout-validated submission must beat ~0.3195 and ideally approach 0.4413. The Korea7 candidate (korea7-k7-offcatalogue-relay-corridor-30000dots-…zeros.tif) is unique and structurally valid, but its score is not yet measurable (data-access blocker), so it carries a negative verdict until holdout DTI is measured.

How to submit (fixes the "[0, 1]" error)

  1. Download the GeoTIFF from index.html (one-click, top of the page).
  2. On DrivenData GEMS Prize → New submission, choose the single .tif file.
  3. Values must be in [0, 1] and finite inside the footprint: this file passes that gate (no NaN inside, range [0.0, 1.0]) — it will not trigger the "Predicted values must be in range [0, 1]" error.
  4. Enter a Note (<=140 chars): "K7 off-catalogue relay-corridor binary dots; unique vs all GEMSDOE sites; holdout-validated score pending data access."
  5. Submit. Up to 3 feedback submissions per week; choose one final submission.

Validator: single band, float32, EPSG:32611, 3730×3292, transform (100, 0, 243350, 0, -100, 4508550), all gates PASS. See run_card.json.
